**1. There are three types of version control.**

1 Local Version Control
All versions and files are saved ion a local system.

2 Centralized Version Control
A server stores all versions and files and multiple people can connect to and work on the data

3 Distributed Version Control
like Git..... every user has a copy of the repository and can work on their portion localy and push updates as needed.
